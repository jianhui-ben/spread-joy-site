# Spread Joy Collective site: repo context for Claude sessions

Read this file, then [SPEC.md](SPEC.md). SPEC.md is the **site-wide rulebook shared with teammates**; do not edit it without the owner. This file is repo-specific: what is here, how to run it, and where the home page does not yet follow the spec.

## What this repo is

A local workspace for the Spread Joy Collective website, **published by hand on Squarespace 7.1** (nothing is deployed from here; GitHub: jianhui-ben/spread-joy-site, public). It holds:

1. A **local mock** of the site (`index.html` + five pages), generated by `build.py`, for viewing in a browser.
2. **Paste-ready Squarespace code** for the home page in [home-page/](home-page/), generated from the same sources so mock and Squarespace cannot drift.
3. **Tests** for both.

## Commands

```bash
python3 build.py                      # regenerate pages, squarespace/ and home-page/
python3 -m http.server 8011           # preview at http://localhost:8011/index.html
python3 -m unittest discover -s tests # markup, CSS, snippet tests
node --test tests/                    # logic tests (counter, ideas, scroll story, header, hearts)
```

Run both suites before committing. Develop test-first; bugs that only showed up on real Squarespace pages each got a regression test.
