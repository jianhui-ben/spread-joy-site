## How to make the page

1. Add a page. Navigation title **Get Involved**. URL slug `get-involved`. Put it in Main Navigation between Events and How Can We Help. That makes 7 links plus the Give button, which is the spec’s limit of 8.
2. Five native cards or columns, each with the heading and the link below. No “coming soon.”
3. There is no volunteer signup URL on the site. The time card goes to Contact and is marked `[TBD: volunteer signup]`.

## The five ways

- **I have time** — Volunteer at an event or a sock drive. Link to Contact. `[TBD: volunteer signup]`
- **I have something to share** — An item, a service, or an experience. Link to Contact.
- **I want to give** — Button label **Give**, to Givebutter. Do not label it Donate.
- **I have an idea** — A collaboration, a connection, or a skill. Link to Contact.
- **I need support** — Link to How Can We Help (`/volunteer`).
